event loop :

event loop is what allows node js to perform non-blocking i/o
operations - despite the fact that js is single-threaded - by offloading
operations to the system kernel whenever possible


example:

console.log('first task'); //This is a synchronous operation

setTimeout(() => {
    console.log('second task');
}, 0);

console.log('next task'); //This is a synchronous operation

Asynchronous Behavior:

The setTimeout function is a way to schedule a function (callback) 
to be executed after a certain amount of time, 
specified in milliseconds.

 Even with a delay of 0ms, setTimeout doesn't execute 
 the callback immediately. Instead, it schedules the 
 callback function to be added to the event loop’s queue 
 after the current synchronous code has finished executing.

The event loop will then pick up the callback 
from the queue and execute it once all the synchronous
 operations have completed. This is why the callback
  is delayed even with a 0ms delay.

Synchronous JavaScript Execution:
When you invoke readFile, 
Node.js doesn't directly read the file. Instead, it passes 
the task to the underlying operating system. 
Node.js then continues executing other code while
 the system kernel works on reading the file in the
  background.

Example of using promise , async and await

const {readFile} = require('fs')
const { get } = require('lodash')
const getText = (path) =>{
    return new Promise((resolve,reject)=>{
        readFile(path,'utf8',(err,data)=>{
            if(err){
                reject(err)
            }else{
                resolve(data)
            }
        })
    })
}



const start = async() => {
    try 
    {
    const first = await getText('./3.txt')
    const second = await getText('./32.txt')
    console.log(first,second);  
    } catch (error) {
        console.log(error);
        
    }
}

start()

async Keyword:
The async keyword marks a function as asynchronous.
When you use async with a function, 
it automatically returns a Promise 
(even if you don’t explicitly return one).
Inside an async function, you can use the await 
keyword to pause execution until a Promise is resolved.

Using promises with async and await with utils


const {readFile, writeFile} = require('fs')
const util = require('util')

const readFilePromise = util.promisify(readFile)
const writeFilePromise = util.promisify(writeFile)

const start = async() => {
    try 
    {
    const first = await readFilePromise('./3.txt','utf8',)
    const second = await readFilePromise('./32.txt','utf8')
    console.log(second);
    
    await writeFilePromise('./32.txt',"This is being added: HELLO")
    } catch (error) {
        console.log(error);
        
    }
}
